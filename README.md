# Luis y Gloria

Página de descargas publicada con GitHub Pages en https://luis-gloria.com/

- La web está en la raíz del repositorio (`index.html` e imágenes en `img/`).
- GitHub la publica sola en cada cambio en `main` (publicación desde la rama).
- Los botones apuntan siempre a la última versión publicada en Releases, así que no hay que tocar la web al actualizar los programas:
  - Simulador Foto (`luisp193/FOTOGRAFIA`): `releases/latest/download/simulador-foto.apk`
  - qBittorrent para Ubuntu (`luisp193/qBittorrent`): `releases/latest/download/qBittorrent-x86_64.AppImage`
- La versión, fecha y tamaño de cada programa se leen en el navegador desde la API de GitHub.
- `robots.txt` y `sitemap.xml` son para Google (Search Console).
